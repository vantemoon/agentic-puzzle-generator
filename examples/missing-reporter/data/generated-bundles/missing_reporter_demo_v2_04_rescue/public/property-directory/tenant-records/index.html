How active commercial tenant records are published.

Published fields

FieldPurpose
Tenant nameIdentifies the current listed occupant
Lease statusShows whether the listing is active
Responsible managerNames the current office contact after review
Entrance assignmentLinks the unit to an official entrance notice

Versions
