About the Directory

Scope and maintenance of the commercial property directory.

Coverage

The directory covers commercial properties managed by the Mason Street property office. Each matched property shows every current unit, listed tenant, and assigned public or service entrance.

Record maintenance

  • Tenant records are reviewed annually.
  • Entrance changes are published as dated notices.
  • Vacant units remain listed to keep unit sequences complete.
