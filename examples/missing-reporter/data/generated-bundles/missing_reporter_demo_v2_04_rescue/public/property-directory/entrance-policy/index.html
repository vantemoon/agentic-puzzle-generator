Entrance Assignment Policy

How entrances are assigned and documented for warehouse units.

Assignment rules

  • Each occupied unit has one listed routine entrance.
  • Shared loading areas require a dated office notice.
  • Changes take effect on the date printed on the notice.

Public notices

A tenant record links to the current notice when a service entrance is assigned.
