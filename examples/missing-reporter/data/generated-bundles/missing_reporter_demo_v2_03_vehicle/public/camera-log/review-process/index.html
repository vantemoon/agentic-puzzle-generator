Camera match review process

How automated camera matches are reviewed and updated.

Review steps

  • The system creates an initial automated match.
  • A reviewer checks the plate, timestamp, and camera station.
  • Approved changes appear in a dated reviewed version.
  • Earlier released versions remain available in record history.
