About shared files

How Northline billing files and attachments are shared.

File scope

Shared invoice packages contain the invoice number, vendor material, and attachments cited by the invoice. Access is limited to the supplied package link.

Included material

  • Invoice summary
  • Cited receipts and notices
  • Links to the original record publisher when available

This package preserves an approved Northline payment document and its cited attachment. The documents are presented together so their references can be checked against the original record publishers.
