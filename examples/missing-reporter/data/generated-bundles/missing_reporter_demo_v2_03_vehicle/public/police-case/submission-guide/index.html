Evidence submission guide

What to expect when sending a record to an existing police case.

Case-specific forms

A case attachment may link to a form requesting one or more exact record fields. Enter only the requested values and review the confirmation before sending.

Before submitting

  • Confirm that the form names the correct case.
  • Use the format shown beside each field.
  • Do not add unrelated personal information.
