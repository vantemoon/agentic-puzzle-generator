About payment files

Scope and publication rules for Harbor Point payment records.

Published records

The repository indexes approved payment documents for Harbor Point contracts and provides retrieval by File ID.

Record notes

  • Contract searches show comparable indexed vendor rows.
  • File IDs are printed on file labels.
  • Attachments remain part of the retrieved payment document.
